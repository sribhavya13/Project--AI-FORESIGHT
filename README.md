# Project FORESIGHT

## AI-Powered Demand & Inventory Intelligence Platform

### Overview
Project FORESIGHT is an AI-powered demand and inventory intelligence platform developed as an internship project at Zidio Development. The platform leverages machine learning to forecast product demand and provide actionable inventory insights.

### Features
- 19 Interactive Dashboards
- Demand Forecasting (Prophet, Random Forest, Linear Models)
- Stockout & Overstock Risk Analysis
- Inventory Optimization
- Customer Insights

### Technology Stack
- **Dashboard**: Streamlit
- **Data Processing**: Pandas, NumPy
- **Machine Learning**: Scikit-learn, Prophet, XGBoost, LightGBM
- **Visualization**: Plotly, Matplotlib, Seaborn
